#BinCardApp
Приложение по поиску информации по BIN банковских карт. Написано по тестовому заданию.

Стэк:
- Jetpack Compose
- MVVM
- Hilt
- Retrofit
- Room
- Coroutines

Основные фунции:
- Получение доступной информации по BIN банковской карты с сайта https://binlist.net/
- Просмотр истории запросов BIN
